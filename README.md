# 🚀 Javier Puente Piazza — Portfolio

Portfolio web personal construido con **HTML, CSS y JavaScript** puro. Diseño oscuro inspirado en terminal con animaciones de red neuronal en canvas.

## ✨ Características

- **Animación de red neuronal** — Fondo interactivo con partículas conectadas (Canvas API)
- **Typewriter** — Efecto de escritura y borrado automático de roles profesionales
- **Scroll Reveal** — Secciones que aparecen con animación al hacer scroll (IntersectionObserver)
- **Menú responsive** — Hamburguesa animada con panel lateral en móvil
- **Formulario de contacto** — Con validación y apertura de cliente de correo
- **Back-to-top** — Botón flotante que aparece al bajar por la página

## 📂 Estructura

```
├── index.html    → Estructura y contenido
├── style.css     → Estilos, responsive y animaciones
├── script.js     → Lógica interactiva y canvas
└── README.md
```
